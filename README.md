# MIRACLE SKILLS — 민진홍 소장의 스킬 갤러리

한 번 받으면 평생 소장하는 민진홍 소장의 스킬을 보여 주는 **갤러리 사이트**입니다.
스킬을 누르면 설명이 열리고, 설명 하단의 버튼을 누르면 **카페**로 이동해 결제·다운로드합니다.

- 가격: 스킬 1개당 **일반 110,000원 / 멤버십 회원 55,000원**
- 판매 기간: 각 스킬은 **공개된 달 한 달만** 판매합니다. 지난 스킬은 "판매 종료"로 표시되고 설명만 볼 수 있습니다.
- 서버·DB·결제 연동이 없는 정적 사이트입니다. 결제와 다운로드는 모두 카페에서 진행합니다.

## 스킬 올리는 방법

`skills/` 폴더에 **같은 이름의 이미지와 글 파일**을 한 쌍으로 넣습니다.

```
skills/
  001.png   ← 갤러리 이미지 (세로 4:5 권장, 예: 1200×1500)
  001.txt   ← 설명문
  002.jpg
  002.txt
```

- 파일 이름 앞의 숫자 순서대로 번호(SKILL 001, 002 …)가 붙습니다.
- 이미지 형식: png, jpg, jpeg, webp, gif
- `_` 또는 `.`으로 시작하는 파일은 빌드에서 제외됩니다. 작성 요령은 `_형식-안내.txt`를 참고하세요.

### 글 파일(.txt) 형식

```
제목: 전자책 출판 지원 스킬
요약: 아이디어 발굴부터 기획, 집필, 홍보까지 12단계로 한 권을 끝까지 완성합니다.
공개월: 2026-10
카페: https://cafe.naver.com/100ai/12345
태그: 출판, 글쓰기
---
여기부터는 본문입니다. 줄바꿈이 그대로 표시됩니다.
```

| 키 | 필수 | 설명 |
|---|---|---|
| 제목 | ✔ | 스킬 이름 |
| 요약 |  | 카드와 설명 창 상단에 나오는 한 줄 소개 |
| 공개월 | ✔ | `YYYY-MM` 형식. 이 달에만 "카페에서 받기" 버튼이 활성화됩니다. |
| 카페 (또는 링크) | ✔ | 이 스킬의 카페 게시글 주소. 비워 두면 `site.json`의 `cafeUrl`로 이동합니다. |
| 태그 |  | 쉼표로 구분 |
| 일반가 / 회원가 |  | 기본값(110,000 / 55,000)과 다를 때만 입력 |
| 상시판매 |  | `예`로 적으면 공개월과 관계없이 계속 판매합니다. |

판매 상태는 방문 시점의 한국 시간을 기준으로 자동 계산됩니다.

- 이번 달: **판매 중 (D-n)**
- 지난 달: **판매 종료**
- 다음 달 이후: **공개 예정**

## 빌드

```bash
node build.mjs     # dist/ 생성 (의존성 없음, Node 18 이상)
```

`dist/index.html`은 더블클릭해서 바로 열 수 있습니다. 이미지와 글 파일의 짝이 맞지 않거나 공개월 형식이 틀리면 빌드할 때 경고가 표시됩니다.

## 사이트 설정 — `site.json`

| 키 | 설명 |
|---|---|
| brand / brandSub | 로고 옆 이름, 첫 화면의 작은 제목 |
| headline / subline / limitedLine | 첫 화면 문구 (`\n`으로 줄바꿈) |
| price / memberPrice | 기본 일반가 / 회원가 |
| cafeUrl | "카페 바로가기" 버튼과 기본 이동 주소 |
| membershipUrl | "멤버십 알아보기" 버튼 주소 |
| siteUrl | 실제 도메인 (예: `https://example.com`). 입력하면 SNS 미리보기 이미지 주소가 절대 주소로 바뀝니다. |

## 배포 (Vercel)

설정이 `vercel.json`에 들어 있어서 저장소를 연결하면 그대로 배포됩니다.

- Build Command: `node build.mjs`
- Output Directory: `dist`
- Framework: Other

`skills/`에 새 스킬을 올리고 커밋하면 자동으로 다시 배포됩니다.

## 폴더 구조

```
index.html  styles.css  app.js   ← 화면
build.mjs                         ← skills/ → dist/ 빌드
site.json                         ← 사이트 문구·가격·링크
skills/                           ← 스킬 이미지 + 설명
assets/                           ← 파비콘, SNS 미리보기(og.png), 프로필 사진
```

> 이 저장소는 공개 상태이므로 유료 파일(스킬 원본)은 절대 올리지 마세요. 이 사이트에는 소개 이미지와 설명만 둡니다.
